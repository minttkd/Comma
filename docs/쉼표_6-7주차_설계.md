## 6주차 — 시나리오 명세

**필수 기능**: F1 AI 품목 판정(쿠팡·무신사 필요/애매/충동 + 식료품 여부, 배민은 판정 없이 애매·충동) · F2 트리거와 강도(재정위험 전환점·고액 단건·몰아치기 → 가벼움/보통/강함) · F3 AI 질문 대화·결과 기록.

**기준 수치(이수민, 10일째 밤)**: 수입 100만 − 고정지출 50만 − 식비 예산 10만(마트 4만 + 쿠팡 식료품 6만) = 여윳돈 40만. B ≈ 13,300원(상한 2B ≈ 26,700원), 고액 기준 ≈ 4만 원. 남은 여윳돈 28만 ÷ 20일 → Q 14,000원 → 적용 한도 14,000원. 오늘 누적: 점심 외식 8,000원(여윳돈).

**정상 경로**
1. 배민 실행 → 동기화 1시간 경과 → 백그라운드 동기화, 점심 외식 8,000원이 오늘 누적에 반영
2. 치킨 세트 23,000원 [주문하기] → 메뉴명·금액 추출, 배민이므로 품목 판정 생략
3. 결제 후 누적 31,000원 > 한도 14,000원 → 재정위험 전환점 → 강도 보통, 첫 질문 미리 생성
4. S06 질문 1 "지금 배고픈 거예요, 치킨이 당기는 거예요?" → [치킨이 당겨요]
5. 질문 2 "이 주문이면 오늘 한도를 17,000원 넘어요. 주말까지 미뤄도 괜찮을까요?" → [주말도 괜찮아요] → 결정을 담은 답이라 바로 그만두기로 연결
6. 오버레이 닫힘 → S08 토스트 "23,000원, 쉼표 찍었어요" → 방지 실적 저장, 홈 반영

대안 A: 5단계에서 [오늘 먹을래요] → 숙고 후 결제 → 다음 날 S09 회고.

**예외 경로**
- E1 취소: X → 오버레이만 닫힘. 같은 화면에서 결제 버튼을 다시 누르면 하던 질문부터 재표시(강도 유지, 새 개입 아님). 결제 화면을 떠나면 자기결정 이탈
- E2 가벼움: 무신사 소품 30분 안에 3건째 → 몰아치기만 → 이유 칩 1개 선택 → 이유 선택 결제
- E3 강함: 무신사 울 코트 129,000원(재정위험+고액) → 질문 3개(과거 연결 1개 직접 입력, "급여일까지 하루 약 7,500원") → 결정 없으면 S07 결정 화면
- E4 판정 예외: 쿠팡 휴지·세제 26,000원 필요(비식료품)지만 재정위험 → 보통에서 한 단계 낮춰 가벼움
- E5 식비 예산: 쿠팡 계란·우유·두부 18,000원 식료품+필요, 식비 잔액 안 → 개입 없음, 식비 잔액 47,000원
- E6 반복: 그날 세 번째 개입 → 한 단계 올림(가벼움 → 보통)
- E7 시스템 실패: 판정 2초 초과 → 애매, 질문 생성 지연 → 기본 질문
- E8 동기화 실패: 캐시로 진행, 홈에 마지막 동기화 시각 표시

**완료 기준**
- AC-1 결제 화면이 뜨기 전(목표 1.5초) 판정·트리거·강도 결정·첫 질문 준비 완료
- AC-2 필요(비식료품)+고액·재정위험 아님, 또는 식료품+필요+식비 잔액 안 → 오버레이 없음, 비개입 기록. 식료품 결제는 오늘 누적을 바꾸지 않음
- AC-3 트리거 해당 → 강도에 맞는 화면(가벼움 S05 / 보통·강함 S06), 트리거 사유와 [그만둘게요]가 처음부터 보임. [결제 계속] 없음
- AC-4 [그만둘게요] 또는 미루는 답 → 1초 안에 닫힘, 방지 실적 저장, 홈 즉시 반영
- AC-5 보통 질문 2개, 강함 질문 3개(1개 직접 입력)에 답해야 [그래도 살게요] 표시. AI는 통과·불통과를 판정하지 않음
- AC-6 모든 개입 화면에 X 상시 노출, 다시 열면 하던 질문부터, 강도 유지
- AC-7 AI 지연·실패 시 흐름 중단 없음

**결과 기록 분류**: 방지 실적 · 이유 선택 결제 · 숙고 후 결제 · 자기결정 이탈 · 비개입 기록 · 사후 회고 응답(다음 대화의 과거 연결 질문 재료).

## 7주차 — User Flow · 화면 구조

**조건 분기**
- D1 동기화 1시간 경과? → 예: 백그라운드 동기화 / 아니오·실패: 캐시
- D2 배민 주문? → 예: 애매·충동 기준 / 아니오: D3
- D3 AI 품목 판정 → 애매·충동·응답 실패: D6 / 식료품+필요: D4 / 필요(비식료품): D5
- D4 식비 잔액 안, 고액 아님? → 예: 식비 차감, 개입 없음 / 고액 또는 식비 초과: D6
- D5 고액 또는 재정위험? → 아니오: 개입 없음 / 예: 재정위험·고액 2개만 평가
- D6 트리거 해당? → 없음: 개입 없음 / 해당: D7
- D7 강도 결정 → ① 조합(몰아치기만·고액만 가벼움 / 재정위험 보통 / 재정위험+고액·여윳돈 0 이하 강함) ② 필요면 −1 ③ 그날 3번째부터 +1 → 가벼움 S05 / 보통·강함 S06
- D8 마지막 답에 결정? → 미루기: S08 / 사기: 숙고 후 결제 / 없음: S07 결정 화면

**화면 목록** (★ 핵심 와이어프레임 · Figma에는 S01~S10 전체 와이어프레임이 사용 순서대로 있음)
- S01 권한 안내 · S02 계좌 연동(정기소득 판별) · S03 고정지출 5항목 + 식비 예산 확인(월 여윳돈)
- S04 홈 ★ · S05 가벼움 이유 칩 ★ · S06 AI 질문 대화 ★ · S07 결정 화면 ★ · S08 처리 완료 ★ · S09 사후 회고 ★
- S10 월말 리포트(마음 돌림 비율, 방지 금액, 강도·트리거별 결과, 회고 후회율)

**전체 와이어프레임 (Figma, S01~S10)**
- S01 권한 안내: 읽는 것/읽지 않는 것 고지, 필수 2(접근성·다른 앱 위 표시) + 선택 1(알림)
- S02 계좌 연동: 은행 선택(Mock), 조회 동의, 정기 수입 판별 "매달 25일 · 약 100만 원"
- S03 고정지출·식비 예산: 고정 5항목 합계 50만, 식비 10만(마트 4만 + 쿠팡 식료품 6만 첫 달 임시값), 월 여윳돈 40만 · 하루 기준액 약 13,300원
- S10 월말 리포트: 마음 돌림 비율 42%(12번 중 5번), 아낀 돈 128,000원, 회고 후회 2/6, 강도별 멈춘 비율, 결과 분류, 식비 예산 보정(다음 달 92,000원)

**개입 화면 배경 (실제 앱 주문 단계 재현)**
- S05: 쿠팡 주문/결제 (받는사람 정보 · 로켓배송 도착 보장 · 결제정보 · 결제수단 · [결제하기]) — 예시를 쿠팡 휴지·세제 26,000원(E4)으로 변경, 태그 재정위험 전환점 + 필요 판정 (11/3 Hi-Fi에서 '한 단계 낮춤' 문구는 삭제)
- S06: 배민 주문하기 (배달 방식 · 주소 · 요청사항 · 결제수단 · 할인쿠폰 · 결제금액 · [23,000원 결제하기])
- S07: 무신사 주문서 (배송 정보 · 주문 상품 · 할인 혜택 · 결제 수단 · 결제 금액 · [129,000원 결제하기])
- S08: 배민 장바구니(이전 화면) 위 토스트
- 로고·상표 이미지는 쓰지 않고 구조와 문구만 단순화해 재현
