# 쉼표 Android 프로토타입 — 실행·에뮬레이터 테스트 가이드

배달의민족·쿠팡·무신사의 **결제 준비 화면**을 접근성 서비스로 읽어, 쉼표 PRD(질문 기반 개입 + 야식 반복 트리거)대로 결제 화면 위에 질문을 띄우는 앱입니다.

> ⚠️ **실제 결제 주의**: 실제 앱에서 테스트할 때 오버레이에서 [그래도 살게요]나 이유 칩을 고른 뒤 앱의 결제 버튼을 누르면 **진짜로 결제됩니다.** 테스트는 [그만둘게요] 또는 뒤로 가기로 끝내세요. 결제 이후 흐름은 앱 안의 **데모 결제 화면**으로 확인하세요.

---

## 1. 빌드·설치 (Android Studio)

1. Android Studio(최신 버전)에서 **Open → `shimpyo` 폴더**를 엽니다. Gradle 동기화가 자동으로 필요한 파일(AGP 8.7.3, Gradle 8.11.1, Android SDK 34)을 받습니다. SDK 34가 없다고 나오면 안내에 따라 설치하세요.
2. **Device Manager → Create Virtual Device** → Pixel 7 같은 기기 → 시스템 이미지는 **"Google Play" 표시가 있는 API 34** (Intel/AMD PC는 x86_64, Apple Silicon Mac은 arm64-v8a)를 고릅니다. 세 앱을 Play 스토어에서 설치하려면 Google Play 이미지여야 해요.
3. 상단 ▶ Run으로 `app`을 실행하면 에뮬레이터에 쉼표가 설치됩니다.

## 2. 처음 실행 (온보딩 S01~S03)

1. **S01 권한 안내** → [접근성 설정 열기] → 설정 › 접근성 › (다운로드한 앱 / 설치된 앱) › **쉼표 결제 감지** › 사용 → 돌아오기
   - "제한된 설정" 안내가 뜨면: 설정 › 앱 › 쉼표 › 오른쪽 위 ⋮ › **제한된 설정 허용** 후 다시 켜기. (Android Studio로 설치하면 보통 뜨지 않아요.)
2. **S02 계좌 연동(Mock)** → 수입·급여일 확인 → 동의 → 다음
3. **S03 고정지출·식비 예산** → 값 확인 → [쉼표 시작하기]

## 3. 시나리오 맞추기 (설정 탭 › 테스트 도구)

| 버튼 | 하는 일 |
|---|---|
| ① 시나리오 10일째로 맞추기 | 주기 10일째, 남은 여윳돈 280,000원 → 적용 한도 14,000원 |
| ② 점심 외식 8,000원 추가 | 오늘 누적 8,000원 (계좌 동기화 Mock) |
| ③ 지난 며칠 야식 3건 추가 | 다음 배민 야식이 "이번 주 4번째"가 됨 |
| ④ 시각 강제 23시 | 낮에도 야식 시간대로 간주 |

## 4. 데모 결제 화면으로 먼저 확인 (실제 앱 없이)

홈 › **데모 결제로 체험하기** 카드에서 시나리오를 고르면 배민·쿠팡·무신사 주문 화면(로고 없는 재현)이 열려요. **결제하기를 누르면** 그때 판단합니다. 같은 엔진·같은 오버레이를 씁니다. 처음엔 3개만 보이고, "다른 시나리오 4개 더 보기"로 나머지를 열 수 있어요.

| 데모 상품 | 준비 | 기대 결과 |
|---|---|---|
| 배민 · 치킨 세트 23,000 | ①② | 재정위험 → **보통**, 질문 2개 (한도 17,000원 초과) |
| 배민 · 떡볶이 12,000 | ①③④ | 야식 반복 → **가벼움**, "이번 주 네 번째 야식이에요 · 4번 합계 51,000원" |
| 배민 · 떡볶이 12,000 | ①②③④ | 재정위험 + 야식 반복 → **보통**, 질문 2가 야식 패턴 질문 |
| 배민 · 회·초밥 45,000 | ①③④ | 재정위험 + 고액 + 야식 → **강함**, 질문 3개(1개 직접 입력) |
| 쿠팡 · 휴지·세제 26,000 | ①② | 필요 판정 → 보통에서 한 단계 낮춰 **가벼움** |
| 쿠팡 · 계란·우유·두부 18,000 | ① | 식료품 + 필요 → 식비 예산 차감, **개입 없음** |
| 무신사 · 울 코트 129,000 | ① | 재정위험 + 고액 → **강함**, 결정 화면 "하루 약 7,500원" |
| 무신사 · 머리끈 4,500 | 연속 3번 결제 | 몰아치기 → **가벼움** |

확인할 것: X → 오버레이만 닫힘 → [결제하기]를 다시 누르면 **하던 질문부터** 다시 뜸 / [그만둘게요] → 이전 화면 + 토스트 "○○원, 쉼표 찍었어요" / 다음 날 홈 위에 **어제 결제 돌아보기** 시트(S09, 만족해요·후회돼요) / 리포트 탭 **마음 돌림 비율**(S10).

## 5. 실제 배민·쿠팡·무신사에서 테스트

> 버전 확인: 쉼표 › 설정 탭 › **앱 버전 0.11**.
>
> 0.11 변경: 홈에 "N월 리포트" 입구 카드를 "이번 달 멈춘 결제" 위에 따로 두고(누르면 카테고리 리포트), "이번 달 멈춘 결제"를 누르면 이번 달 멈춘 결제 목록만 보여 줘요. 홈 최근 기록과 기록 화면에는 실제로 결제한 내역만 보여요.
>
> 0.10 변경: 홈 "오늘 쓸 수 있는 돈" 왼쪽 위에 숨숨이를 넣고, 돈 상태에 따라 표정이 바뀌어요(여유 웃음 · 주의 갸웃 · 초과 걱정). 오른쪽 위 여유/주의/초과 태그는 빼고, 한도를 넘으면 "N원 초과" 글자를 빨간색으로 보여 줘요.
>
> 0.9 변경: 홈은 0.7 모양으로 되돌리고 "N원 초과" 표기 · "주기 N일째" 삭제, 홈의 데모 결제 카드와 설정의 AI(API 키 · 모델 · 대기 시간) 입력을 뺐어요(데모 결제 화면은 설정 › 테스트 도구에서 열 수 있어요). 리포트는 카테고리별 지출 원형표(배달 음식 · 옷/패션 · 생활용품 · 식료품 · 외식 · 기타) → 다음 날 "후회돼요"를 누른 결제와 그 카테고리 → 앞으로 줄이고 싶은 결제(여러 개 선택, 바로 저장, 이번 달 쓴 돈 함께 표시)로 바꿨어요.
>
> 0.8 변경: 홈 "오늘 쓸 수 있는 돈" 막대가 오늘 쓴 돈을 채우고, 한도를 넘으면 넘은 부분이 빨갛게 이어져요(사이 흰 틈이 한도 위치). 아래에 "오늘 쓴 돈 · 오늘 한도"를 나란히 보여 줘요. 여윳돈 · 식비 타일은 남은 돈을 크게, 막대는 쓴 만큼 채우고 "쓴 돈 19만 / 40만 원"으로 보여 줘요.
>
> 0.7 변경: 앱 화면 안의 "쉼표" 글자를 없앴어요(홈 제목, 개입 시트 이름표, 토스트 등). 개입 시트 머리줄은 숨숨이 오른쪽에 "오늘 31,000원 쓰게 돼요 / 한도 14,000원 · 17,000원 넘어요"처럼 이 결제로 오늘 돈이 어떻게 되는지 두 줄로 보여 주고, "잠깐, 쉼표 하나 찍을까요?" 제목은 뺐어요. 기록 태그 이름은 안 샀어요 · 이유 있어 샀어요 · 고민하고 샀어요 · 식비 지출 · 여윳돈 지출로 바꿨고, 색은 초록(안 샀어요) · 노랑(고민하고 샀어요) · 회색(나머지) 세 가지로 줄였어요.
>
> 0.6 변경: 서비스 캐릭터 **숨숨이**(쉼표 잎을 단 찹쌀떡)를 넣었어요. 개입 시트 머리줄(숨 고르기)·질문 말풍선(궁금해요)·"그만둘게요" 토스트(뿌듯해요)·홈 "이번 달 쉼표" 상자·빈 기록 화면에 나와요. 결제 기록 줄은 "배민 · " 같은 글자 대신 왼쪽에 **앱 아이콘**을 보여 줘요. 아이콘은 휴대폰에 깔린 배민·쿠팡·무신사 앱의 아이콘을 그대로 가져오고, 앱이 없으면(에뮬레이터 등) 첫 글자 배지로 대신해요.
>
> 0.5 변경: 화면 전체를 Figma Hi-Fi 프로토타입(쉼표 와이어프레임) 디자인으로 바꿨어요. 판단 엔진·질문·기록 방식은 그대로예요. 0.2부터는 결제 화면에 들어가도 개입하지 않고, 결제 버튼 위에 **파란 테두리(가드)**가 생긴 뒤 그 버튼을 누를 때만 개입합니다. 테두리는 설정 탭 › 테스트 도구에서 끌 수 있어요.
>
> 0.3 변경: [그만둘게요]나 "다음에 살게요" 같은 중단 칩으로 멈춘 뒤 30분 안에 같은 앱에서 결제 버튼을 다시 누르면, 첫 화면 맨 위에 "아까는 멈추셨어요. 다시 결제하려는 이유가 있나요?" 한 줄이 붙습니다(배민은 "주문"). 질문과 한도 계산은 그대로입니다.


1. 에뮬레이터 Play 스토어에 로그인 → 배달의민족 / 쿠팡 / 무신사 설치 → 각 앱 로그인
2. 설정 탭에서 ①②(필요하면 ③④) 실행
3. 각 앱에서 상품을 담고 **결제 버튼이 보이는 주문 화면**(배민 "주문하기", 쿠팡 "주문/결제", 무신사 "주문서")까지 들어갑니다.
4. 결제 화면에 들어오거나 쿠폰으로 금액이 바뀌어도 개입하지 않습니다. 쉼표가 결제 버튼 위에 투명 가드를 올려 두었다가, **결제 버튼을 누르는 순간** 최종 금액(쿠폰 적용 후)으로 판단해 오버레이를 띄웁니다. 개입이 필요 없으면 누른 터치가 그대로 결제 버튼에 전달됩니다. 개입 후 [그래도 살게요]를 고르면 가드가 풀리니 결제 버튼을 한 번 더 누르세요. 테스트는 [그만둘게요]로 끝내세요.

### 감지되지 않을 때

쉼표 › 설정 탭 맨 아래 **"마지막으로 읽은 화면 텍스트"**와 **감지 로그**를 확인하세요.

- 첫 줄 `[결제버튼=…, 결제섹션=…, 완료화면=…, 금액=…]`에 판단 근거가 나옵니다.
- 텍스트가 거의 비어 있으면 그 화면이 접근성으로 읽히지 않는 구조(웹뷰·보안 처리 등)입니다.
- 이 텍스트를 복사해서 보내 주시면 해당 앱에 맞게 판별 규칙(`ScreenParser.java`)을 조정할게요.
- PC에서 화면 구조를 직접 보려면: `adb shell uiautomator dump /sdcard/ui.xml && adb pull /sdcard/ui.xml`

### 에뮬레이터에서 생길 수 있는 문제

- 일부 앱은 에뮬레이터·루팅 환경을 감지해 실행이나 로그인을 막을 수 있어요. 이 경우 실기기(안드로이드 폰)나 데모 결제 화면으로 시연하세요.
- 배민은 휴대폰 본인인증이 필요할 수 있어요.
- 오버레이 위 직접 입력에서 키보드가 안 뜨면 에뮬레이터 설정 › 시스템 › 키보드에서 화상 키보드를 켜세요.

## 6. AI (선택)

설정 탭 › AI에 Claude API 키를 넣으면 쿠팡·무신사 품목 판정과 질문을 AI가 만듭니다. 키가 없거나 응답이 늦으면(기본 2,000ms) 키워드 판정·기본 질문으로 바로 대체합니다. 에뮬레이터·실제 네트워크에서 AI 응답이 2초를 자주 넘기면 대기 시간을 3,000~4,000ms로 늘려 보세요. 기본 모델은 `claude-haiku-5-5`이고 설정에서 바꿀 수 있어요. (0.4부터. 0.3에서 기본값 `claude-haiku-4-5`를 그대로 쓰던 경우 0.4로 업데이트하면 자동으로 `claude-haiku-5-5`로 바뀝니다.)

## 8. 이번 프로토타입의 한계

- 계좌 연동은 Mock입니다 (앱 실행 시 동기화 시각만 갱신, 외식 등은 테스트 도구로 추가).
- 결제를 실제로 막을 수는 없습니다 (숙고 유도). 결제 완료 여부는 결제 버튼 클릭·완료 화면 문구로 추정하고, 잘못 기록된 건은 기록 탭에서 길게 눌러 지울 수 있어요.
- 사후 회고는 잠금 해제 알림 대신 홈 화면 카드로 보여줍니다.
- 첫 달 식비 자동 보정, 대화 요약은 표시만 하거나 생략했습니다.
